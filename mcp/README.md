# aqg-mcp — MCP server for agentic-quality-gate

Exposes `run_quality_gate` to Cursor / VS Code Agent.

## Install (from your app repo)

```bash
cd /path/to/your-app && curl -fsSL https://raw.githubusercontent.com/pulumamidi-harsha/agentic-quality-gate/main/scripts/install-app.sh | bash && export PATH="$HOME/.local/bin:$PATH" && hash -r
```

Then type `run-qg` in the terminal, or ask Agent: `run-qg`

Full steps: [../README.md](../README.md).
